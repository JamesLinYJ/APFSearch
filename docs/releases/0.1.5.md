# APFSearch 0.1.5 Preview

修复某些索引持续显示扫描中的问题。大量硬链接的目录不再为每个新路径重复核对整个链接集合；挂载信息中无关的标志变化也不会再反复中断恢复。路径替换、权限失败和真实卷变化仍会重新核对，不提前推进事件进度。

本版本沿用现有数据库、配置和派生缓存格式，无须重建索引。它仍是开发预览版。

下载提供 **Apple Silicon、Intel、Universal** 三种版本，每种均有 DMG 和 ZIP。应用与 DMG 均通过 Developer ID 签名及 Apple 公证；ZIP 包含已装订公证票据的应用。最低系统版本为 macOS 14。

发布现在使用 GitHub Actions：先验证源代码，再在临时钥匙串中签名、公证，核对所有下载文件后公开发布。凭据只存于受限的 GitHub release 环境 Secrets，运行日志和下载包不包含私钥。

验证范围：329 项 Rust 测试、121 项 Swift 服务/内容/文件检查，以及本机签名应用的真实硬链接、替换、目录改名和删除验证。实际服务已完成初始扫描和积压事件恢复；这些结果不代表新的跨机器性能基准。

---

Fixes prolonged scanning in directories with many hard links. Discovering another path to an unchanged file object no longer rechecks its entire alias set. Irrelevant mount-flag changes no longer repeatedly interrupt recovery. Actual identity changes, permission failures and replacements still require reconciliation before event progress advances.

Existing databases, settings and derived caches remain usable. No index rebuild is required. This remains a development preview.

Choose **Apple Silicon, Intel or Universal**, as DMG or ZIP. Applications and DMGs are Developer ID signed and Apple notarized; ZIPs contain the stapled application. Requires macOS 14 or later.

GitHub Actions now validates, signs and notarizes releases using a temporary keychain, then verifies the complete download set before publication. Credentials remain in the restricted release environment Secrets and are excluded from logs and artifacts.

Validation includes 329 Rust tests, 121 Swift service/content/file checks, and installed signed-app checks for hard links, replacement, directory renames and deletion. The local service completed its initial scan and queued event recovery. This is correctness evidence, not a new cross-machine performance benchmark.
