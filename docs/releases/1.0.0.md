# APFSearch 1.0.0

APFSearch 首个正式版，提供独立于 Spotlight 的文件名、路径和元数据搜索，原生 macOS 界面，以及与主界面共享索引服务的命令行工具。

## 本次更新

- 修复后台索引服务被卸载后，重新打开应用仍无法连接的问题。确认后台运行仍获授权后，通过系统 ServiceManagement 接口注销失效注册，等待完成后重新注册。
- 自动恢复最多尝试一次，用户主动重试可再次触发恢复；后台权限被撤回时不会强行重新启动服务。
- 连接失败不会自动重做移动、复制、删除等文件操作，避免原操作已经完成却被重复执行。
- 延续 0.1.6 的紧凑列式索引、共享快照、增量更新和新版 SDK 构建，在支持的 macOS 上采用原生 Liquid Glass。

## 下载与升级

提供 **Apple Silicon、Intel、Universal** 三种架构，各有 DMG 和 ZIP，最低支持 macOS 14。应用及 DMG 通过 Developer ID 签名和 Apple 公证；ZIP 包含已装订公证票据的应用。

从 0.1.6 升级保留现有 SQLite 索引、设置和派生缓存；协议、缓存格式和内部构建号保持不变，不因本次升级重建索引。更早版本可能需要从现有 SQLite 生成新版派生缓存，详见 [0.1.6 升级说明](https://github.com/JamesLinYJ/APFSearch/blob/v1.0.0/docs/releases/0.1.6.md)。

正式版不代表与 Everything 完全等价。真实 Intel 硬件、macOS 14 实机和长期整卷负载仍需更多验证；本次未改动查询算法，也不宣称新的性能提升。具体限制见 [README](https://github.com/JamesLinYJ/APFSearch/blob/v1.0.0/README.zh-CN.md#当前限制)。

---

APFSearch's first stable release provides filename, path and metadata search independently of Spotlight, a native macOS interface, and a command-line client using the same index service.

## Changes

- Recover an authorized background indexer whose launchd job was unloaded while ServiceManagement still reports it enabled. Use the system APIs to unregister, wait for completion, and register again.
- Limit automatic recovery to one attempt, renewed by an explicit retry. Respect revoked background approval.
- Never replay move, copy, trash or other requests after a transport failure: the original operation may already have completed.
- Retain 0.1.6's compact columnar index, shared snapshots, incremental updates and modern SDK builds, including native Liquid Glass on supported macOS versions.

## Downloads and upgrading

Choose **Apple Silicon, Intel or Universal**, as DMG or ZIP, for macOS 14 or later. Apps and DMGs are Developer ID signed and Apple notarized; ZIPs contain the stapled application.

Upgrading from 0.1.6 retains SQLite data, settings and derived caches. The protocol, cache format and internal build number are unchanged; this upgrade does not require rebuilding the index. Earlier versions may regenerate their derived cache from existing SQLite data; see the [0.1.6 upgrade notes](https://github.com/JamesLinYJ/APFSearch/blob/v1.0.0/docs/releases/0.1.6.md).

A stable release does not imply complete Everything compatibility. Physical Intel hardware, macOS 14 and long-running full-volume workloads still need more validation. No query algorithm changes or new performance gains are claimed in this release. See [current limitations](https://github.com/JamesLinYJ/APFSearch/blob/v1.0.0/README.md#current-limitations).
