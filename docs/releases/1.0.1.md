# APFSearch 1.0.1

修复选择搜索结果时的界面卡顿，并减少大量文件变动时的后台重复计算。

## 本次更新

- 路径栏直接使用已有索引数据构建原生组件，选择文件时不再让 AppKit 在界面线程同步读取路径属性和文件图标。避免文件系统或 iCloud / FileProvider 响应慢时拖住选择操作；路径栏双击定位和拖放仍保留。
- 路径栏图标按原生小号控件字体配置尺寸，修复文件、文件夹和磁盘图标偏大、与文字不协调的问题。
- 退役已删除文件的核对诊断时，使用集合查找替代逐条交叉比较及临时字符串分配，减少大量删除、重命名时的 CPU 消耗。保留原来的路径匹配、覆盖报告和事件进度语义。
- 保留查询算法、索引范围、SQLite 数据、派生缓存、设置及公开协议。内部构建号仍为 1；无需因本次升级重建索引。

## 下载与验证

提供 **Apple Silicon、Intel、Universal** 三种架构，各有 DMG 和 ZIP，最低支持 macOS 14。应用和 DMG 通过 Developer ID 签名与 Apple 公证；ZIP 包含已装订公证票据的应用。

本地验证通过 361 项 Rust 测试及 100 项 AppKit 界面检查，并验证了签名应用中的连续选择、滚动、搜索和访达定位。尚未复测 iCloud 大规模同步压力场景；本次修复针对 APFSearch 的同步阻塞调用，不代表修复了系统 FileProvider。Intel 和 macOS 14 实机验证仍有限。

Fix selection stalls and reduce redundant background work during large filesystem changes.

## Changes

- Populate the native path bar from indexed metadata instead of asking AppKit to resolve path attributes and file icons synchronously on the UI thread. Selection no longer waits on that filesystem or iCloud / FileProvider work. Preserve breadcrumb double-click reveal and dragging.
- Size path-bar symbols to the native small-control font, fixing oversized file, folder and drive icons.
- Retire removed-file diagnostics using a set lookup instead of comparing every diagnostic with every removed path and allocating temporary strings. Preserve path-matching, coverage and event-progress semantics.
- Keep query algorithms, index scope, SQLite data, derived caches, settings and the public protocol unchanged. The internal build number remains 1; this upgrade does not require an index rebuild.

## Downloads and validation

Choose **Apple Silicon, Intel or Universal**, as DMG or ZIP, for macOS 14 or later. Apps and DMGs are Developer ID signed and Apple notarized; ZIPs contain the stapled application.

Local validation passed 361 Rust tests and 100 AppKit checks, plus continuous selection, scrolling, searching and Finder reveal in the signed app. Large-scale active iCloud synchronization was not reproduced; this fixes APFSearch's synchronous blocking path, not the system FileProvider. Physical Intel and macOS 14 validation remains limited.
